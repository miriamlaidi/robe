## Zensical documentation
This site is generated with Zensical, a static site generator: the pages are written in Markdown and Zensical turns them into a website.

### Project structure
```
bpm-doc-1/
├── zensical.toml      # site configuration and navigation menu
└── docs/
    ├── index.md       # home page and introduction
    ├── physics.md      # physic context
    ├── classBPM.md      # BPM class
    ├── gui.md         # GUI interface
    └── results.md           # Final results
```
Each .md file in docs/ is one page of the site.
